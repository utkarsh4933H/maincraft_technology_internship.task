# Student Performance Management System (SQL Internship Task - 1)

This project is developed as part of Internship Task 1 to demonstrate basic SQL database management and data analysis skills.
The project focuses on creating a student database, inserting records, and performing different SQL operations for data retrieval and analysis.

## Objectives

* Understand database creation using SQL
* Practice CRUD operations
* Perform data analysis using SQL queries
* Learn aggregate functions and filtering techniques

## Features Implemented

* Created a `students` table using SQL
* Inserted multiple student records
* Displayed all student information
* Calculated average marks for each subject
* Identified the top-performing student
* Counted students according to grades
* Generated average scores based on gender
* Filtered students using conditions
* Updated student grade records

## Technologies Used

* PostgreSQL
* SQL

## SQL Concepts Covered

* CREATE TABLE
* INSERT INTO
* SELECT Statement
* WHERE Clause
* GROUP BY
* ORDER BY
* Aggregate Functions (`AVG`, `COUNT`)
* UPDATE Statement

## Outcome

This task helped in improving practical knowledge of SQL queries, database handling, and student performance analysis.
